# Telleo landing (telleo.ai)

Marketing site for **Telleo**: Vacademy's AI voice calling, launched as its own product.
Static Next.js 15 + Tailwind 4 export, same stack and deploy path as vacademy.io and tutezy.ai.

## Run

    pnpm install
    pnpm dev          # http://localhost:3000
    pnpm build        # static export in ./out (+ out/llms-full.txt)
    pnpm typecheck

## Deploy (Cloudflare Pages, Git integration)

- Framework preset: **Next.js (Static HTML Export)** · build `pnpm build` · output `out` · `NODE_VERSION=20`
- Custom domain `telleo.ai` (+ `www` redirect)
- After deploy: submit `https://telleo.ai/sitemap.xml` in Google Search Console and Bing Webmaster Tools, and
  check Cloudflare → Security → Bots that "Block AI bots" is **off** (robots.txt welcomes AI crawlers on purpose)

## The truth file

`docs/PRODUCT_FACTS.md` lists every claim the site may make, read from the platform code and the CRM docs on
2026-09-25, plus a "Never claim" list and the sourced third-party facts (HBR 2011, TRAI PR 119/2026).
**Change the product → change this file first, then the copy.**

## Structure

| What | Where |

| Site constants (test line, WhatsApp, sales email, booking URL) | `src/lib/site.ts` |
| Hand-written pages registry (titles + meta descriptions) | `PAGES` in `src/lib/site.ts` |
| Nav / footer lists | `src/lib/nav.ts` |
| Every URL (sitemap + llms-full) | `src/lib/routes.ts` |

| Hero call animation | `src/components/HeroCallDemo.tsx` |
| Product mock visuals | `src/components/Visuals.tsx` |
| Demo form → CRM + email | `src/components/DemoForm.tsx`, `src/lib/leadSubmit.ts` |
| AI-crawler summary | `public/llms.txt` (hand-curated); `public/llms-full.txt` is generated by `pnpm build` |

SEO: every page has its own title/description/canonical, Open Graph image, BreadcrumbList JSON-LD, and where
relevant FAQPage / Product / Article / BlogPosting / ItemList schema. Organization + WebSite + SoftwareApplication
are in `src/app/layout.tsx`.

## Before launch (owner to-dos)

1. **Mailbox**: `hello@telleo.ai` is shown sitewide. Create it, or change `SALES_EMAIL` in `src/lib/site.ts`.
2. **Booking link**: set `BOOKING_URL` in `src/lib/site.ts` (empty = every "Book a demo" goes to `/demo/`).
3. **Test line**: +91 80356 14126 (Telleo trial line since 2026-10-09; set in `TEST_LINE` in `src/lib/site.ts`). The old
   vacademy.io test-drive line, +91 80353 74489, is no longer used on the site.
4. **Leads**: the form posts to the *Vacademy Website* CRM audience with Campaign Name "Telleo – Book a demo".
   That audience dedups by email, so someone who already enquired on vacademy.io is not recorded again.
   A dedicated Telleo audience fixes it (swap `CRM_AUDIENCE_ID` + field ids in `src/lib/leadSubmit.ts`).
5. **Lead email**: the shared `vacademy-send-email` Worker (`landing_page/workers/send-email`) needs a
   `telleo.ai/api/send-email*` (+ `www.`) route and a `telleo` entry in `BRANDS`; until then only the CRM receives leads.
6. **Analytics**: the site loads the vacademy.io GTM container (`GTM-5C4DDJ6W`), which also fires the Vacademy
   Meta pixel and Ads tags on telleo.ai. Add a hostname condition or use a separate container.
7. **Confirm**: the Enterprise tier (no public price), the demo promise ("we'll set up an agent around your use
   case and call your phone"), and how TRAI's Sept 2026 A2P declaration is handled for customers' AI calls.
8. The sample recording `public/audio/telleo-sample-call-admissions-2.mp3` is a real Shiksha Nation admissions
   call (5:12). It names the institute and a child ("Srishti"); confirm you have permission to publish it.
